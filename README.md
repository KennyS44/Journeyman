# Journeyman — кодекс мастера

Хранилище материалов для мастеров настольных ролевых игр. Статический сайт,
без сервера: всё лежит в браузере пользователя.

Как устроено внутри и почему именно так — [ARCHITECTURE.md](ARCHITECTURE.md):
слои, потоки данных, выбор IndexedDB против localStorage (с замерами),
рекурсивный спуск против `eval`, известные ограничения.

Разбор каждой функции по отдельности — [CODE-WALKTHROUGH.md](CODE-WALKTHROUGH.md):
что делает, почему сделано так и чем за это заплачено.

## Запуск на своём компьютере

    git clone https://github.com/KennyS44/Journeyman.git

Дальше сборка не нужна — это чистые HTML/CSS/JS. Откройте `index.html`
двойным щелчком. Проверено в Chrome: приложение работает, данные сохраняются
и переживают перезапуск браузера.

Если браузер запрещает локальным файлам хранилище (так бывает в отдельных
сборках Firefox), поднимите простой сервер в папке проекта и откройте
`http://localhost:8000`:

    python3 -m http.server 8000

Две оговорки:

- `file://…/index.html` и `http://localhost:8000` — для браузера **разные
  origin**, у каждого своё хранилище. Выберите один способ и держитесь его,
  иначе покажется, что материалы пропали.
- Шрифты Cinzel и Spectral подгружаются с Google Fonts. Без интернета вид
  останется целым, но текст отрисуется запасным шрифтом с засечками.

## Как устроено

- **Меню** — список «Пространств» (кампания, город, подземелье). Можно создать,
  открыть и удалить.
- **Пространство** — свободный холст. На него добавляются *ключевые объекты*:
  карточка с картинкой и наименованием. Карточку можно свободно таскать мышью
  или пальцем — положение сохраняется. Сам холст двигается перетаскиванием пустого
  места, масштабируется колесом или щипком, «Показать всё» подгоняет обзор.
- **Инструмент «Связь»** — включается на панели внизу. Нажатие по двум объектам
  протягивает между ними нить. Нажатие по самой нити предлагает её разорвать.
- **Внутренняя директория объекта** — открывается нажатием по наименованию.
  В середине текст объекта (сохраняется сам): полужирный, курсив, подзаголовки,
  списки, **таблицы** и **картинки прямо в тексте**. Нажатие по картинке
  показывает углы — потяните за любой, чтобы менять размер; пропорции
  сохраняются, размер запоминается. Справа панели: кубики, калькулятор,
  изображения и видео, музыка, пометки, связанные директории.
  Музыку можно пустить в мини-плеер, который переживает переходы между экранами.
  Громкость общая для всего приложения: она запоминается и остаётся прежней
  при переходах между объектами и после перезапуска.
- **Кубики** — отдельная панель: выберите кубик (d4…d100) и количество (до 20),
  нажмите «Бросить». Кубики крутятся, и только потом выпадают значения; каждый
  новый бросок стирает прошлый. Показывается каждый кубик и сумма.
- **Калькулятор** — обычная арифметика со скобками и дробями, история последних
  вычислений (нажатие подставляет выражение обратно).
- **Заметки плана** — сворачивающаяся вкладка слева. Открытая занимает половину
  места и сдвигает текст объекта вправо. Держится при переходах между объектами
  одного плана и закрывается при переходе в другой план: у каждого плана свои
  заметки.
- **Кодекс целиком** — внизу меню две кнопки: сохранить всё в один файл и
  загрузить его обратно. Отдельное пространство сохраняется кнопкой в его
  шапке. Подробнее ниже.

## Файлы

    index.html      единственная страница, точка входа
    css/app.css     оформление: пергамент и старое золото
    js/db.js        хранилище на IndexedDB (записи + файлы как Blob)
    js/ui.js        помощники: окна, иконки, уведомления, выбор файлов, очистка HTML
    js/zip.js       чтение и запись zip — без сторонних библиотек
    js/backup.js    сохранение кодекса в файл и загрузка обратно
    js/calc.js      разбор выражений с кубиками и сам калькулятор
    js/app.js       оболочка: маршруты, общая шапка, мини-плеер
    js/demo.js      демо-сцена для первого запуска на пустом хранилище
    js/screens/menu.js    экран #/ — список пространств
    js/screens/space.js   экран #/s/<id> — холст, карточки, связи, масштаб
    js/screens/node.js    экран #/n/<id> — текст объекта, панели, свиток плана
    demo/           обложки и музыка демо-сцены
    tests/          проверки парсера выражений и упаковщика

## Тесты

Разбор выражений и упаковщик покрыты тестами. На сайт они не влияют — это
отдельные файлы для запуска в Node:

    node tests/calc.test.js
    node tests/zip.test.js

Упаковщик заодно проверяется на совместимость с системными `zip` и `unzip`:
собранный архив прогоняется через настоящий архиватор, а созданный им —
читается нашим кодом. Если этих программ в системе нет, обе проверки
пропускаются.

Полный круг в настоящем браузере — `tests/roundtrip.browser.js`: набивает
кодекс, сохраняет в файл, стирает базу, загружает обратно и сверяет побуквенно.
Ему нужен Playwright, поэтому он вынесен отдельно; как запускать, написано в
шапке файла.

## Хранение данных

Записи и файлы лежат в IndexedDB того браузера, где их загрузили; положение
камеры на холсте и громкость звука — в localStorage. Объём ограничен квотой
браузера (обычно сотни мегабайт и больше). Данные **не** синхронизируются
между устройствами — для этого понадобился бы сервер с учётными записями и
хранилищем файлов.

## Кодекс целиком: файл `.jm.zip`

Хранилище браузера — не вечное: чистка данных сайта, переустановка системы или
другой компьютер означают, что материалов больше нет. Поэтому весь кодекс
складывается в один файл.

Это обычный zip, внутри — `codex.json` с записями и папка `assets` с
изображениями, видео и музыкой как они есть. Его можно открыть любым
архиватором и достать свои картинки, даже если этой страницы под рукой не
окажется. Файлы кладутся без сжатия: медиа и так сжаты своими форматами, а
текст рядом с ними весит пренебрежимо мало.

Загрузка **добавляет**, а не заменяет: пространства из файла встают рядом с
теми, что уже есть, с новыми идентификаторами. Повторная загрузка того же
файла сделает копию — это заметно и поправимо, в отличие от стёртой кампании.

Тем же файлом материалы переезжают в [настольную версию](https://github.com/KennyS44/Journeyman-Desktop)
и обратно: формат у них общий.

Две оговорки:

- Архив собирается целиком в памяти. Для кодекса на сотни мегабайт музыки
  на слабой машине это может не получиться — программа предупредит заранее.
- Имя скачанного файла записывается латиницей: кириллицу в имени часть
  браузеров теряет вместе с расширением. В настольной версии имя сохраняется
  как есть — там за сохранение отвечает системный диалог.
