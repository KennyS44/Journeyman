# Journeyman — кодекс мастера

Хранилище материалов для мастеров настольных ролевых игр. Статический сайт,
без сервера: всё лежит в браузере пользователя.

## Запуск на своём компьютере

    git clone https://github.com/KennyS44/Journeyman.git

Дальше сборка не нужна — это чистые HTML/CSS/JS. Откройте `index.html`
двойным щелчком. Проверено в Chrome: приложение работает, данные сохраняются
и переживают перезапуск браузера.

Если браузер запрещает локальным файлам хранилище (так бывает в отдельных
сборках Firefox), поднимите простой сервер в папке проекта и откройте
`http://localhost:8000`:

    python3 -m http.server 8000

Две оговорки:

- `file://…/index.html` и `http://localhost:8000` — для браузера **разные
  origin**, у каждого своё хранилище. Выберите один способ и держитесь его,
  иначе покажется, что материалы пропали.
- Шрифты Cinzel и Spectral подгружаются с Google Fonts. Без интернета вид
  останется целым, но текст отрисуется запасным шрифтом с засечками.

## Как устроено

- **Меню** — список «Пространств» (кампания, город, подземелье). Можно создать,
  открыть и удалить.
- **Пространство** — свободный холст. На него добавляются *ключевые объекты*:
  карточка с картинкой и наименованием. Карточку можно свободно таскать мышью
  или пальцем — положение сохраняется. Сам холст двигается перетаскиванием пустого
  места, масштабируется колесом или щипком, «Показать всё» подгоняет обзор.
- **Инструмент «Связь»** — включается на панели внизу. Нажатие по двум объектам
  протягивает между ними нить. Нажатие по самой нити предлагает её разорвать.
- **Внутренняя директория объекта** — открывается нажатием по наименованию.
  В середине текст объекта (сохраняется сам): полужирный, курсив, подзаголовки,
  списки, **таблицы** и **картинки прямо в тексте**. Справа панели: калькулятор,
  изображения и видео, музыка, пометки, связанные директории.
  Музыку можно пустить в мини-плеер, который переживает переходы между экранами.
- **Калькулятор** считает и обычную арифметику, и броски кубиков: `2d6+3`,
  `d20+5`, `4d6*2`. Показывает выпавшее по каждому кубику и хранит историю.
  Понимает русские «к» и «х» (`2к6`, `2х3`).
- **Заметки плана** — сворачивающаяся вкладка слева. Открытая занимает половину
  места и сдвигает текст объекта вправо. Держится при переходах между объектами
  одного плана и закрывается при переходе в другой план: у каждого плана свои
  заметки.

## Файлы

    index.html      единственная страница, точка входа
    css/app.css     оформление: пергамент и старое золото
    js/db.js        хранилище на IndexedDB (записи + файлы как Blob)
    js/ui.js        помощники: окна, иконки, уведомления, выбор файлов, очистка HTML
    js/calc.js      разбор выражений с кубиками и сам калькулятор
    js/app.js       экраны, холст, связи, редактор текста, автосохранение

## Хранение данных

Записи и файлы лежат в IndexedDB того браузера, где их загрузили; положение
камеры на холсте — в localStorage. Объём ограничен квотой браузера (обычно
сотни мегабайт и больше). Данные **не** синхронизируются между устройствами —
для этого понадобился бы сервер с учётными записями и хранилищем файлов.
